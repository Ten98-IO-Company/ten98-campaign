# Application audit coverage

Reviewed on 18 October 2026. This pass traced existing server functions, API actions, UI handlers and their callers across the application. It checked normal, empty, invalid, unauthorized, failed, stale, concurrent and retry states, with focused regressions for reproduced defects. Coverage is grouped by workflow and action; it does not mean every function or branch has its own test. Source review and simulated-provider testing do not establish live provider acceptance or imply that every provider capability is implemented.

## Automated verification

The checks use temporary or in-memory databases, synthetic identities and simulated provider HTTP. They exercise actual application routes and handlers, including failure and concurrency paths. UI checks include production-handler timing tests and source/element assertions; they do not replace browser interaction tests.

The full automated suite passed **244 checks**, with no failures, skips or cancellations. The production TypeScript and Vite build passed, and `npm audit --omit=dev` reported no known production dependency vulnerabilities. Focused provider, workflow and UI runs are subsets of this suite, not additional totals. See [verification](verification.md) for release commands and evidence.

## Limits

- This audit performed no real publication, message, upload, booking, campaign activation or ad spend. Live credentials, OAuth grants, developer-token approval, product/creative eligibility, quotas, billing, delivery and report availability still require authorized provider accounts.
- Standard Google Video campaigns remain read-only in this app. Native creation is unsupported; supported Demand Gen video creation uses Zernio. See [Google's Video API limits](https://developers.google.com/google-ads/api/docs/video/overview) and [advertising setup](advertising.md). Copilot or other AI placement eligibility does not guarantee impressions; organic search performance remains in ten98 Discover.
- Email is transactional only. Replies are routed externally through Cloudflare Email Routing and the configured mailbox/group; voice campaigns and a receiving email inbox are excluded. Hygiene/DNS checks do not prove mailbox existence. See [direct campaigns](direct-campaigns.md).
- Short-link and QR counts are requests, not unique people or verified conversions. Event intake is bounded and stores aggregate data; resource locks and background processing retain the documented single-instance deployment limits. See [tracking](tracking.md) and [operations](../README.md#deployment-and-operations).
